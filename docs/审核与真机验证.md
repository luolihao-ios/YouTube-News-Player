# 审核与真机验证说明

## 技术路线及已落实行为

App 的首页、分类搜索、收藏排序、观看记录及设置为原生 SwiftUI。只有播放器使用系统 WKWebView，加载官方 YouTube IFrame Player API。

使用实际 Bundle ID 组成 HTTPS baseURL 和 origin，符合 YouTube 的 API 客户端标识要求。保留播放器控件、品牌与广告，不遮挡播放器，不抓取媒体地址，不提供下载、音轨分离或后台播放。全屏、字幕、画质通过官方控件操作。播放器视口至少200×200。

首次嵌入前显示第三方数据处理说明与 Google 隐私链接，用户确认后才创建 WebView；设置中仅能撤回同意。观看记录须主动启用，关闭即清空。无账号、无自建分析服务。频道和图片请求仍会连接 Google，不应将“没有自建分析”误写为“没有任何第三方数据处理”。

## 正式提交前仍需完成

1. 在 Apple 开发者账户注册实际 Bundle ID，配置签名、App Store Connect App 及版本资料。
2. 设置可用且具备配额的 YouTube API Key，核对频道 handle、允许嵌入和计划发行地区的可用性；正式版使用者不需自行申请 Key。
3. 由运营者发布真实隐私政策及支援网址。文案须说明 YouTube / Google 数据处理、联系方式、资料删除与当地要求；应用内说明不能替代 App Store Connect 的公开 URL。
4. 根据实际网络行为、第三方服务及官方说明填写 App Privacy 标签。`PrivacyInfo.xcprivacy` 当前描述 App 自身的 UserDefaults 使用，不等于对 YouTube 数据收集的完整声明，也不能据此直接勾选“未收集任何数据”。如加入追踪行为，需重新评估 ATT 与相关声明。
5. 确认内容、商标和频道目录使用符合 YouTube 条款及权利人的要求；按 Apple 要求提供相关使用许可说明。采用官方 API 不等同于拥有全部内容授权。
6. 真机执行下面的验证，保存结果，然后 Archive、签名并提交。需要真实截图，不能把参考图、设计图或模拟数据当作成品截图。

## 真机验证项目

- 首次安装无Key：明确显示尚未配置，无假直播、假观看数字。
- 有Key：检查首页三频道发现、原生分类与中英文搜索、API错误和配额耗尽。
- 官方播放：首次告知同意、拒绝/关闭后不创建播放器；设置无法绕过告知。
- 启动和暂停：实际点击官方播放按钮后记录观看；进后台、锁屏、关详情页均暂停；返回不自动恢复；换台只存在一个播放器。
- 嵌入失败：删除/私人影片100、禁嵌入101/150、身份错误153、无网络、WebKit进程退出及连接超时有清楚提示和官方入口。
- 官方控件：字幕、画质、全屏、广告与品牌完整可见；没有原生按钮或提示覆盖视频。
- 收藏：添加去重、滑动删除、编辑排序、重启持久化、空列表推荐、换一批。
- 缓存：15分钟后标记过期，24小时淘汰；刷新不续期旧头像；清除缓存期间的旧请求不能回写。
- 首页：台湾已有直播时，切到未查询的国际分类仍显示该分类精选频道。
- 隐私：观看记录默认关闭、启用记录、关闭清空、清除所有资料后旧请求不恢复资料。
- 版本：启动不查询；每次打开设置查询一次；新版图标、点击App Store、无App Store ID时不发查询。
- iPhone小屏、iPad、多任务窄屏、深色模式、动态字体与VoiceOver；检查文字截断、按钮可用及旋转。
