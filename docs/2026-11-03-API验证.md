# YouTube API 联通验证

使用 `Config/Local.xcconfig` 中的本机 Key 进行验证，Key 未写入报告、命令参数或源码。

## 实测结果

- `channels.list`：目录 12 个频道全部成功返回身份及真实频道标题。
- 首页 TVBS、三立新闻、中天的 `search.list` 和 `videos.list` 均成功，返回公开、直播中、允许嵌入的影音及官方提供的观看人数。
- 这是 Windows 上的真实 HTTP API 验证，不是 Swift 客户端执行、iOS WebKit 播放或审核通过的证明。
- 部分海外版直播具有台湾地区限制；允许嵌入不等于任意地区可播。

## 本次修正

初次实测发现 `setnews`、`CtiTv`、`FRANCE24_English`、`BloombergTV` 这四个原目录标识无法作为当前 handle 解析。通过 API 核对实际身份后，目录改用稳定的 YouTube Channel ID 查询和打开官方频道，不再依赖旧 handle。原目录 `id` 保持不变，避免已有收藏关系变化。

新增永久目录测试，先确认旧目录因缺少稳定身份而失败，再补齐目录后验证通过。另新增 Swift 核心测试，验证旧 handle 失效时仍按固定 Channel ID 发请求、频道链接仍有效；该 XCTest 尚待 Mac 执行。

## 重复验证

```sh
python scripts/check_youtube_api.py
```

默认批量查验全部频道身份，仅发现首页三个频道的直播，避免不必要的搜索配额消耗。报告保存在 `.test-output/youtube-api-check.json`。`--live-limit 0` 可只查频道身份。

尚需 Mac/Xcode 编译及真机验证，未生成 IPA、未提交审核。
