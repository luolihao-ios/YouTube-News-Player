# 新闻直播实现计划

> **执行方式：** 本会话直接实现，按用户全程自主执行要求推进；使用 executing-plans 的任务检查与 TDD 流程。

**目标：** 交付参考 UI 对应的 SwiftUI 新闻直播 App 和官方 YouTube API 集成。
**架构：** NewsCore Swift Package 隔离模型、API、筛选与本机资料；App 层实现原生 UI、WKWebView 与生命周期。播放器 HTML 单独打包，可在 Windows 测试桥接行为。
**技术：** Swift 5.9、SwiftUI、WebKit、URLSession、XCTest、Node 内建测试。
**设计：** `docs/superpowers/specs/2026-10-27-news-live-design.md`

## 全局约束
- 最低 iOS 17；原生界面仅播放器内嵌网页。
- 项目文档中文；不写入真实 Key；不虚构直播/观看人数。
- 保留官方播放器、广告、控件；暂停离屏播放器。

## 重点验证
- API 请求正确过滤直播及嵌入状态；错误区分缺少 Key、配额、网络和频道不存在。
- 搜索空白、大小写、分类组合；损坏收藏资料与重复收藏。
- HTML 注入、非法 video ID、错误 100/101/150/153、暂停和销毁。
- API 缓存过期、离线保留可用内容、后台暂停与退出释放。
- 版本比较、设置页触发、无 App Store ID 不发请求。
