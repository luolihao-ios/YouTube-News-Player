# 新闻直播 iOS 设计

## 目标与约束
以用户提供的四屏参考图为基准，实现原生 iOS 新闻直播聚合器。用户后续明确要求内嵌 WebKit、使用 YouTube API、以 App Store 上架为目标。按其自主执行要求直接落实；平台选择为 SwiftUI + WKWebView，最低 iOS 17。

## 方案
采用原生 SwiftUI 首页、频道列表、收藏和设置，只有播放器由 WKWebView 承载 YouTube IFrame Player API。网页整体套壳对原生体验和审核价值帮助有限；解析媒体地址、自建播放器不符合本项目的官方 API 路线，因此不采用。未创建或发布 Sites 网站。

## 页面与行为
- 首页：红白视觉、精选频道、真实直播缩略图、分类入口、最近观看。未检查状态不冒充正在直播。
- 频道：本地即时搜索、分类过滤、按需查询直播、下拉刷新。使用精选频道的 YouTube handle，经 channels.list 解析频道身份，不抓取网页。
- 播放：官方 iframe 控件、来源链接、原生收藏、系统分享、频道简介和相关频道。退出及退到后台暂停；禁止下载、提取媒体、隐藏广告或覆盖官方播放器。
- 收藏：本机持久化、编辑删除、排序；推荐未收藏频道。观看记录默认关闭，用户启用后才保存，支持清空。
- 设置：外观、记录开关、数据清除、隐私与条款、版本。打开设置时查询一次 App Store 版本；不在启动时检查更新。

## API 与状态
YouTube Data API v3 负责频道解析、直播发现、标题、缩略图和真实同时在线人数。没有返回人数时不显示虚构数字。使用按需请求、15 分钟直播发现缓存、24 小时频道元数据缓存；持久化 API 数据最长 24 小时，过期删除。无 Key 时展示明确配置状态，不静默使用假数据。Release 构建必须配置开发者 API Key，普通使用者无需提供 Key。

## 审核与交付边界
WKWebView 使用官方要求的 Bundle ID HTTPS baseURL / Referer 标识，保持官方播放行为。首次播放前说明第三方数据处理并取得确认。提供应用内隐私说明和 YouTube / Google 条款入口；正式发布仍需真实运营者、隐私政策网址、App Store ID、签名、有效 Key、内容权利确认和真机测试。技术组合不等于 Apple 保证批准。

当前环境为 Windows，没有 Xcode/iOS SDK。交付可在 Xcode 打开的工程、Swift 核心单元测试、播放器 JavaScript 测试和 macOS CI。Windows 可验证的检查与尚未执行的 iOS 构建必须分别报告。
